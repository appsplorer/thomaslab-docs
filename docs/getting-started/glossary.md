# Healthcare research and HPC glossary

- **Adapter:** Reviewed mapping from one source schema to a canonical contract.
- **AUROC:** Area under a receiver-operating-characteristic curve; not calibration.
- **CATE:** Conditional average treatment effect; causal only under stated assumptions.
- **CI:** Continuous integration: automated tests on a specific Git commit.
- **CPIC:** Clinical Pharmacogenetics Implementation Consortium.
- **CYP2D6 / CYP2C19:** Pharmacogenes whose allele interpretation requires versions.
- **DUA:** Data-use agreement defining lawful access and permitted actions.
- **EHR:** Electronic health record.
- **FHIR:** Fast Healthcare Interoperability Resources.
- **G-formula:** G-computation standardizing estimated outcomes under interventions.
- **HCRU:** Healthcare resource utilization.
- **HPC:** High-performance computing with allocated jobs/storage.
- **IRB/HRPP:** Human research oversight and human participant protections.
- **IPW:** Inverse probability weighting; depends on positivity/model assumptions.
- **NLP:** Natural language processing of clinical text.
- **OMOP CDM:** Observational Medical Outcomes Partnership common data model.
- **PGx:** Pharmacogenomics.
- **PHI:** Protected health information.
- **Positivity:** Sufficient nonzero treatment probabilities within target strata.
- **Propensity score:** Conditional probability of treatment given covariates.
- **SLURM:** HPC workload manager with `sbatch`, `squeue` and `sacct`.
- **Synthetic data:** Fabricated records; not a substitute for external validation.
- **Time zero:** Study-defined start of eligibility, assignment and follow-up.
- **Transportability:** Validity of applying an effect/model to a new target population.

This glossary simplifies concepts; refer to a study's protocol and technical
method documentation for full assumptions.
