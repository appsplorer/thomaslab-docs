# Choose a starting path for your research role

## Clinicians and pharmacists

Start with [the synthetic first session](first-session.md), read
[research-use boundaries](../reference/research-use.md), then review
[phenotype and endpoint definitions](../guides/phenotype-endpoints.md),
[PGx](../guides/pgx.md) and [method readiness](../guides/method-readiness.md).
Clinical validation requires named human review; never prescribe from demos.

## Clinical epidemiologists and health-services researchers

Read [dataset onboarding](../tutorials/dataset-onboarding.md),
[causal study designs](../guides/causal-epi-workflow.md),
[leakage protection](../guides/leakage-protection.md) and
[external validation](../guides/external-validation.md). Prespecify estimands.

## Data scientists and ML engineers

Start with [installation](installation.md),
[healthcare foundation](../guides/healthcare-foundation.md),
[model evaluation](../guides/evaluation.md), and
[scientific review](../tutorials/scientific-review.md). Record exact SHA,
dependency versions and data fingerprints.

## Research administrators and HPC maintainers

Use [A–Z HPC setup](../guides/hpc-a-to-z.md),
[governed notebook deployment](../guides/governed-notebook-use.md),
[audit and traceability](../guides/audit-traceability.md) and
[release gates](../guides/lab-validation-release-criteria.md).
Institutional authorizations cannot be created by this software.
