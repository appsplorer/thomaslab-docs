# API reference

Browse the [stable v1 function reference](../reference/functions/README.md) covering 571 documented callables across 69 baseline modules. An additional **10 candidate clinical/disclosure module references (42 callable signatures)** are listed separately. Candidate signatures are not proof of execution, independent scientific validation or public release readiness.

The implementation repository is private. Publication of this documentation does not authorize access to institutional records or clinical decision-making. For teaching, begin with the [synthetic first session](../getting-started/first-session.md).
